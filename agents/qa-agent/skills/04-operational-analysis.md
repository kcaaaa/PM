# 阶段4 · 运营分析技能

> 从产品运营和商业决策角度，评估功能的投入产出比、市场竞争力和长期维护成本。

---

## 1. 职责

- 判断该功能是否值得开发（ROI 分析）。
- 评估功能在目标市场中的竞争力。
- 估算上线后的运营成本和维护负担。
- 识别可能被忽略的商业风险或机会。

---

## 2. 输入

| 来源 | 说明 |
|---|---|
| RQ-* | 需求背景、业务问题、成功标准 |
| FT-* | 功能范围（用于估算投入） |
| TD-* | 技术方案复杂度（影响开发成本） |
| 阶段1-3输出 | 产品认知模型 + 用户模拟结果 + 风险评估 |

---

## 3. 分析维度

### 3.1 投入产出比（ROI）评估

| 检查项 | 说明 |
|---|---|
| 开发成本估算 | 基于功能范围和技术复杂度，粗略判断投入量级（低/中/高） |
| 预期收益 | 该功能能解决的核心问题及其业务价值 |
| ROI 合理性 | 投入是否与其带来的价值匹配？是否存在"杀鸡用牛刀"的情况？ |

#### 3.1.1 结构化 ROI 指标模板

> 参考：AgentOps Strategy Guide。ROI 分析应从三类业务结果出发，避免空泛描述。

**降本类指标（Cost Reduction）**
- 人力节省：预计减少的人工操作量 × 单位成本
- 流程加速：缩短的周期时间 × 对应资源成本
- 错误率降低：减少的错误处理/返工成本

**增收类指标（Revenue Growth）**
- 转化率提升：功能上线后对关键转化漏斗的影响
- 客单价提升：是否有助于提高单次交易金额或订阅层级
- 用户留存：是否直接改善留存、复购或续费意愿

**合规/风控类指标（Risk & Compliance）**
- 风险事件减少：预计避免的违规罚款或事故损失
- 审计效率提升：自动化审查/记录带来的合规成本下降
- 品牌保护：降低声誉受损概率的隐性价值

评估方法：
- 对每个相关指标给出"高/中/低"影响判断，并简要说明依据。
- 不需要精确数字（QA Agent 不做财务建模），但要避免"看起来有价值"这种空话。

### 3.2 市场竞争力分析

| 检查项 | 说明 |
|---|---|
| 差异化程度 | 该功能是否是市场上已有的标准能力，还是真正的差异化优势？ |
| 用户吸引力 | 目标用户是否真的在意这个功能？还是"锦上添花"？ |
| 竞品对比 | 同类产品的类似功能表现如何？我们是否有更好的实现可能？ |

### 3.3 长期维护成本

| 检查项 | 说明 |
|---|---|
| 技术复杂度 | 方案是否会导致后续维护和迭代的高昂成本？ |
| 运营负担 | 上线后是否需要大量人工介入（审核、客服、配置）？ |
| 扩展性 | 功能设计是否便于未来扩展，还是容易变成"一次性实现"？ |

### 3.4 商业风险识别

| 检查项 | 说明 |
|---|---|
| 依赖外部因素 | 是否过度依赖第三方服务、政策环境或合作伙伴？ |
| 用户接受度 | 功能是否存在被用户抵触的风险（如隐私敏感、操作繁琐）？ |
| 法律/合规成本 | 是否需要额外的法务审查或合规投入？ |

---

## 4. 评估标准

### 4.1 ROI 分级

| 等级 | 含义 | 建议 |
|---|---|---|
| 高 ROI | 投入合理，预期收益明确且显著 | 推荐推进 |
| 中 ROI | 有一定价值，但需权衡优先级 | 有条件推荐（需确认优先级） |
| 低 ROI | 投入明显高于预期收益 | 建议重新评估或缩减范围 |

### 4.2 竞争力分级

| 等级 | 含义 |
|---|---|
| 强差异化 | 该功能是核心竞争优势，竞品难以快速复制 |
| 中等差异 | 有一定优势，但竞品可能跟进 |
| 跟随型 | 市场上已有类似功能，属于"标配"需求 |
| 弱价值 | 用户关注度低或市场已饱和 |
