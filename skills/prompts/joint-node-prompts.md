# 关节节点提示系统

## 节点定义

| 节点 | 触发条件 | 提示内容 |
|---|---|---|
| 需求确认节点 | 用户确认候选方案 | 说明下一步将进入产品设计阶段，预计耗时 |
| 设计确认节点 | 用户确认设计方案 | 说明下一步将进入技术方案阶段，预计耗时 |
| 方案确认节点 | 用户确认技术方案 | 说明下一步将进入功能实现阶段，预计耗时 |
| 实现完成节点 | 所有功能开发完成 | 说明下一步将进入测试验证阶段，预计耗时 |
| 测试通过节点 | 所有测试用例通过 | 说明下一步将进入部署发布阶段，预计耗时 |
| 发布完成节点 | 应用成功部署 | 提供访问链接，说明后续维护和迭代流程 |

## 提示模板

### 标准关节节点提示

```
✅ [阶段名称]已完成！

下一步操作：
1. [具体下一步动作]
2. [用户需要做的事情]
3. [预期结果]

预计耗时：约 [X] 小时

需要你确认：[确认点（如有）]
```

### 需求确认节点提示

```
✅ 需求已确认！

下一步操作：
1. 我将基于确认的需求设计产品界面和交互流程
2. 你需要审查设计方案并给出反馈
3. 设计确认后进入技术方案阶段

预计耗时：约 [2-4] 小时

需要你确认：是否开始产品设计阶段？
```

### 设计确认节点提示

```
✅ 设计已确认！

下一步操作：
1. 我将基于设计制定技术方案，包括技术栈选择、架构设计、接口定义
2. 你需要审查技术方案并确认
3. 方案确认后进入功能定义阶段

预计耗时：约 [2-4] 小时

需要你确认：是否开始技术方案阶段？
```

### 方案确认节点提示

```
✅ 技术方案已确认！

下一步操作：
1. 我将分解功能任务并开始编码实现
2. 每个功能完成后会进行测试验证
3. 你可以随时查看进度和提出修改意见

预计耗时：约 [4-8] 小时

需要你确认：是否开始功能实现阶段？
```

### 实现完成节点提示

```
✅ 功能实现已完成！

下一步操作：
1. 我将执行单元测试和端到端测试
2. 测试通过后进入部署发布阶段
3. 你需要确认发布到哪个环境

预计耗时：约 [2-4] 小时

需要你确认：是否开始测试验证阶段？
```

### 测试通过节点提示

```
✅ 测试已通过！

下一步操作：
1. 我将部署应用到生产环境
2. 部署完成后提供访问链接
3. 你可以进行最终验收

预计耗时：约 [1-2] 小时

需要你确认：是否开始部署发布阶段？
```

### 发布完成节点提示

```
🎉 发布完成！

应用已成功部署到生产环境。

访问链接：
- 生产环境：[URL]
- 预览环境：[URL]（如有）

后续操作：
1. 进行最终验收测试
2. 监控应用运行状态
3. 收集用户反馈

需要你确认：是否进行最终验收？
```
